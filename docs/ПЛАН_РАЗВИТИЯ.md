# План развития

1. **Смысловой GitHub diff:** сравнение commits, загрузка изменённых `.md/.txt/.yaml/.json/.py`, выделение `SKILL.md`, промптов и чек-листов, hash каждого артефакта. Код не исполнять.
2. **Web/RSS:** RSS/Atom, поисковые API, canonical URL, дата, автор, первоисточник, robots.txt и rate limits.
3. **LLM-анализ:** строгий JSON: тип артефакта, темы, резюме, изменения, оценки 0–5, риски, лицензия, применимость к российским нормам или `unknown`, ссылки-доказательства.
4. **База/UI:** PostgreSQL, источники, снимки, артефакты, версии, события, темы, оценки и feedback; панель управления.
5. **Уведомления:** Telegram/email, ежедневный digest, отдельные сигналы только о значимых изменениях. Ошибка источника не равна отсутствию новостей.
6. **Библиотека:** экспорт Markdown/DOCX/TXT, оригинал отдельно от адаптированной версии, provenance и лицензия.

LLM не выполняет арифметику и не должен выдумывать соответствие СП/ГОСТ. При отсутствии подтверждения ставить `unknown`. Все внешние документы считать недоверенными данными.
